# Photo Editor 2.0 Release 1.0.0

## Wersja 1.0.0

To jest pierwsza wersja stabilna aplikacji Photo Editor 2.0 z pełnymi funkcjami edycji zdjęć.

### Zmiany

- Wdrożono zaawansowany menedżer aktualizacji
- Dodano wiele nowych filtrów i narzędzi edycji obrazów
- ObsługaRAW i EXIF danych
- System cofania/ponawiania zmian
- Automatyczne budowanie wersji dla Linux, Windows i macOS

### Funkcjonalności

1. Wbudowane filtry: Czarno-biały, Sepia, Negatyw, Winietka, Ramka, Ołówek
2. Narzędzia: Auto-korekta, Zmiana rozmiaru, Usuwanie obiektów, Wyprostuj horyzont, Znak wodny
3. System warstw i mieszania obrazów
4. Porównanie zdjęć
5. Konwerter folderów z eksportem do różnych formatów
6. Opcje eksportu: PNG, JPG, PDF, RAW
7. Obsługa schowka (kopiuj/wklej)
8. Pasek narzędzi z narzędziami edycji

### Zainstalowanie

Aplikacja może być zainstalowana przez instalator `.deb` dla Debiana lub uruchomiona bez instalacji przez skrypty `run.sh`/`run.bat`.

### Wymagania systemowe

- Python 3.13+
- Biblioteki Qt6 i OpenCV
- System Linux/Windows/macOS
